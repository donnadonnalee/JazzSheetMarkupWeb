## 1. Metadata
- `title: Song Name` : Sets the title.
- `key: Dm` : Sets the key signature (works with transposition).

## 2. Structure
- `[A]` : Displays a section label.
- `|:` : Repeat Start
- `:|` : Repeat End
- `|` : Double bar line (when at end of line)
- `(1)`, `(2)` : First and second endings (Volta)

## 3. Chords
- `"Cm7"` : Wrap chord names in double quotes.
- `"A(-9,-13)"` : Tensions should be inside parentheses.

## 4. Notes & Rests
- **Pitch**: `c`, `d`, `e`, `f`, `g`, `a`, `b`
- **Octave**:
  - `llc` : Very low (Oct 2)
  - `lc` : Low (Oct 3)
  - `c` : Middle (Oct 4)
  - `hc` : High (Oct 5)
  - `hhc` : Very high (Oct 6)
  - *Note: Octave changes at 'c'.*
- **Accidental**: `+` (Sharp), `-` (Flat)
- **Rest**: `r`
- **Duration**: `c4`, `c2`, `c1`, `c0.5`, `c1/3` (Triplet)
  - No space needed between pitch and duration.

## 5. Layout
- `nl` : Wraps the line starting from the *next* measure.
- `,` : Optional separator within a measure.
