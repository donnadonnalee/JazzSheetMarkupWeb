## 1. メタデータ
- `title: 曲名` : タイトルを設定します。
- `key: Dm` : 曲のキーを設定します（移調に連動）。

## 2. 構造・記号
- `[A]` : セクションラベルを表示します。
- `|:` : リピート開始
- `:|` : リピート終了
- `|` : 複縦線（行の末尾にある場合）
- `(1)`, `(2)` : 1番カッコ、2番カッコ

## 3. コードネーム
- `"Cm7"` : コード名はダブルクォーテーションで囲みます。
- `"A(-9,-13)"` : テンションはカッコ内に記述します。

## 4. 音符と休符
- **音高**: `c`, `d`, `e`, `f`, `g`, `a`, `b`
- **オクターブ**:
  - `llc` : 非常に低い (Oct 2)
  - `lc` : 低い (Oct 3)
  - `c` : 普通 (Oct 4)
  - `hc` : 高い (Oct 5)
  - `hhc` : 非常に高い (Oct 6)
  - ※ オクターブの切り替わり基準は `c` です。
- **臨時記号**: `+` (シャープ), `-` (フラット)
- **休符**: `r`
- **音価**: `c4`, `c2`, `c1`, `c0.5`, `c1/3` (三連符)
  - 音名と数字の間にスペースは不要です。音価を省略すると四分音符となります。

## 5. レイアウト
- `nl` : 次の小節から改行します。
- `,` : 小節内の区切り（任意）。
